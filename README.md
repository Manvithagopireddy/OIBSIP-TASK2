# Chhatrapati Shivaji Maharaj — Tribute Page

> OIBSIP Level 2, Task 2 · Learning project

A static tribute page exploring semantic content structure, typography, imagery and CSS layout.

## Technology

HTML, CSS

## Project structure

`index.html` — page content; `style.css` — layout; `image/` — assets.

## Run locally

```bash
git clone https://github.com/Manvithagopireddy/OIBSIP-TASK2.git
cd OIBSIP-TASK2
```

Open `index.html` in a modern browser. Alternatively, run `python -m http.server 8000` from the project directory and visit http://localhost:8000.
